# P-Value

## Topic Area
Business Statistics - Hypothesis Testing

## Learning Level
Beginner to Intermediate

## Concept Explanation
A p-value helps decide whether the sample evidence is strong enough to reject the null hypothesis.

A small p-value means the observed result is unlikely if the null hypothesis is true.

A large p-value means the observed result is not unusual enough to reject the null hypothesis.

## Decision Rule
If p-value is less than or equal to the significance level, reject the null hypothesis.

If p-value is greater than the significance level, do not reject the null hypothesis.

## Key Formula or Rule
If p-value ≤ α, reject H0.

If p-value > α, do not reject H0.

## Formula Meaning
- p-value means probability value.
- α means significance level.
- H0 means null hypothesis.

## Simple Example
Suppose the significance level is 0.05.

Case 1:
p-value = 0.03

Since 0.03 is less than 0.05, reject the null hypothesis.

Case 2:
p-value = 0.08

Since 0.08 is greater than 0.05, do not reject the null hypothesis.

## Important Note
A p-value does not tell the probability that the null hypothesis is true.

It tells how unusual the sample result is if the null hypothesis is assumed to be true.

## Business Use Case
A marketing manager may use p-value to decide whether a new advertising campaign has significantly improved sales.

A quality manager may use p-value to check whether a process improvement has reduced defects.

## Common Student Doubts

Q1. Is a lower p-value stronger evidence?  
A1. Yes. A lower p-value usually means stronger evidence against the null hypothesis.

Q2. Does p-value prove the alternative hypothesis?  
A2. No. It only provides evidence for decision-making.

Q3. What does p-value less than 0.05 mean?  
A3. It usually means the result is statistically significant at the 5% significance level.

Q4. What happens if p-value is greater than 0.05?  
A4. We do not reject the null hypothesis.
